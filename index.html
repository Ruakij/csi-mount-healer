csi-mount-healer

Helm chart repository for csi-mount-healer, a DaemonSet that remounts dead CSI volumes of running pods through their CSI driver, and keeps pods from writing to the node disk while a mount is missing.

helm repo add csi-mount-healer https://ruakij.github.io/csi-mount-healer
helm repo update
helm install csi-mount-healer csi-mount-healer/csi-mount-healer -n kube-system

Charts are also published as OCI artifacts at oci://ghcr.io/ruakij/charts/csi-mount-healer, which is where prereleases go. The index here lists stable releases only.
